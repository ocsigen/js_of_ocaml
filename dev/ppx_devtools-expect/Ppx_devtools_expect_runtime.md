# Module `Ppx_devtools_expect_runtime`

Runtime of `ppx_devtools-expect`: a small, self-contained reimplementation of the `%expect` machinery with support for environment-conditional snapshots (`%expect.when`) and tag-based skipping (`@tags`).

All values here are called by code generated by the `ppx_devtools-expect` rewriter; they are not meant to be used directly.

```ocaml
module Axes : module type of Axes
```
Predefined axes of `[@when]` predicates.

```ocaml
val version_compare : int list -> int list -> int
```
Lexicographic comparison of version components, used by reified version comparisons.

```ocaml
module Ops : sig ... end
```
The operators used by reified predicates. The generated code refers to them through this module, which, unlike `Stdlib` and its operators, the test module cannot shadow.

```ocaml
type variant = {
  condition : unit -> bool;
  is_default : bool;
  expected : string;
  payload_start : int;
  payload_end : int;
}
```
One environment-specific variant of an `%expect` assertion point.

```ocaml
val register_test : 
  lib:string ->
  filename:string ->
  description:string ->
  line_number:int ->
  start_pos:int ->
  end_pos:int ->
  tags:string list ->
  condition:(unit -> bool) ->
  expectations:variant array array ->
  (unit -> unit) ->
  unit
```
Register an `let%expect_test`. `lib` is the library the test belongs to (so the runner can ignore tests from dependencies linked into it). `expectations` holds one group of `variant`s per assertion point (in source order); `check ~index:k` refers to group `k`.

```ocaml
val check : index:int -> unit
```
Called at each `%expect`/`%expect.when` point: compares the output captured since the previous point against the active variant of group `index`.

```ocaml
val read_output : unit -> string
```
Called for `%expect.output`: returns (and consumes) the output captured since the previous expect point.

```ocaml
val exit : unit -> unit
```
Entry point of the generated inline-test runner. Parses the runner CLI, runs the registered tests under output capture, writes `.corrected` files for mismatches and exits with a non-zero status on failure.
